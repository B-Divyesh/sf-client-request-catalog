# Demo sandbox

Open `/demo` or select **Try it with sample data** on the landing page.

The demo contains three fictional offers for Field & Form sample: a fixed-price
maintenance visit, a price-on-application fitting set, and a repeat supplies
pack. Its request endpoint validates the form and returns a sample receipt. It
does not read or write SQLite. No demo contact details enter the owner inbox.

**Reset demo** clears the browser's current selection and reloads the original
sample. **Start for real** returns to the product landing page. The demo does
not use localStorage, IndexedDB, or a production client token.
